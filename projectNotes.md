# Notes of things I end up learning of / about during this project

## Random Keybinds that are useful
ZSH
- CTRL+U Clear all text in shell
- CTRL+W Clear previous word
- CTRL+K Clear to end of line 

## What is NPM?
Officially: Node Package Manager, default package manager for the Node.js runtime
environment and the world's largest software registry for Javascript.

From my understanding this is analagous to the cmake / make build files that 
are used in C/C++ projects. It is a tool used to source software that the developer
didn't write but used in their own project

## What is Vite?

Modern front-end build tool and local development server. Allows 
developer to simulate changes in real time and see those changes propogate to the local server without having to recompile the project. 

## What is Package.json and Package-lock.json
Package.json defines your project's broad intent, configuration, and acceptable version ranges.

Package-lock.json locks down the exact dependency tree to guarantee identical, reproducible builds across every machine.
